## 2. What this project is

A single-user dashboard that gives *sight* into a job-application pipeline that already
runs on the owner's Mac. The Mac stays the source of truth; the dashboard ingests pushed
snapshots and **never writes back**. Every edit made in the UI is rendered as a
copy-pasteable `track.py` command the owner runs themselves.

```
Personal/Jarvis (Mac, source of truth)
  └─ services/apply/scripts/push_dashboard.py
        └─ POST /api/ingest  (bearer INGEST_TOKEN)
              └─ PostgreSQL (Replit)
                    └─ Express API  ←→  React dashboard
```

The two repos are a matched pair:

| Repo | GitHub | Role |
|---|---|---|
| `Personal/Jarvis_Mission_Control` | `ParshvCrafts/Jarvis_Mission_Control` | this app (the dashboard) |
| `Personal/Jarvis` | `ParshvCrafts/Jarvis` | the pipeline + the push script + the PRD |

Clone **both**. The PRD that specified this app lives in the *other* repo at
`docs/redesign/REPLIT_MISSION_CONTROL_PRD.md`, along with
`docs/redesign/GUIDE-mission-control-connect.md` (the Mac→dashboard wiring guide).

## 4. The security hardening — merged, but not yet test-verified

Commit `c226763`, 15 files, +412/−69, merged into `main` as `5ba70e4` on 2026-08-20.
Its commit message is the full review record — read it directly rather than trusting
this summary:

```bash
git log -1 c226763
```

What it fixes:

| ID | Fix |
|---|---|
| B1 | `sanitize` now *replaces* every shell-active char (backtick, backslash, `!`, `;`, `\|`, `$`, quotes) with lookalikes. Previously only `"` and `$` were escaped, so escaped backticks stayed live when a generated command was pasted into zsh. Fixed in both copies (server `ingestSchema` + dashboard `pendingCommands`) and pinned by tests. |
| B2 | `isValidTrackCommand` allowlist enforced on ingested `reply_suggestions`; `POST /pending-changes` now **ignores** the client's command string and rebuilds it server-side from `(kind, payload)`. |
| M1 | CORS no longer reflects arbitrary origins with credentials. Same-origin by default; `ALLOWED_ORIGINS` for split-host setups. |
| M2 | Owner check fails **closed** — a missing `OWNER_USER_ID` now 503s instead of admitting any authenticated Replit user. |
| M3 | `processIngestPayload` wrapped in one transaction — a mid-payload failure can no longer leave `followups` deleted-but-not-reinserted. |
| M4 | `darwin-arm64` binaries restored in pnpm overrides so the repo builds on a Mac. |
| M5 | `AUTH_MODE`/`OWNER_USER_ID` read per-request (were frozen at import); decorative basic-auth test replaced with a real 200/401/`WWW-Authenticate` e2e test. |
| M6 | `DEV_SKIP_AUTH` removed from `.replit [userenv.shared]` — every dev preview had been fully unauthenticated. Now set only in the vitest config. |
| — | `trust proxy` enabled (the rate limiter had been seeing the proxy IP for everyone). |

### How it was merged, and how to undo it

Merged with `--no-ff`, so the eight fixes stay one identifiable unit rather than being
smeared into `main`'s history. That makes the rollback a single atomic operation. There is
**no schema change** in the merge, so a revert is clean — nothing to un-migrate.

```bash
# preferred — safe on a pushed branch, preserves history
git revert -m 1 5ba70e4

# only if it had never been shared (it has been, so don't)
git reset --hard pre-merge-security-2026-08-20
```

The `fix/security-review` branch was intentionally **not deleted** after merging: it is
the traceable home of the review, and it costs nothing to keep. Delete it only once you
are confident the merge is staying.

Full command list is in [`replit.md`](../replit.md) §Development commands.

**Watch out for these two, both of which have cost time before** (they are recorded in
`.agents/memory/`, which the Replit agent reads automatically):
- A typecheck error claiming a `@workspace/db` column "does not exist" means a stale
  `lib/db/dist/*.d.ts`. Run `pnpm exec tsc -b lib/db --force` *before* working around it.
- Hand-written Zod must `import { z } from "zod/v4"`, and the OpenAPI spec must never use
  `format: uri` (Orval emits `zod.url()`, which fails typecheck).

## 9. Standing constraints — do not let these erode

Repeated here because they are the whole point of the design, and an agent with fresh
context will otherwise "helpfully" violate them. Full list in [`replit.md`](../replit.md).

- The Mac is the source of truth. The server never mutates pipeline data on its own.
- **Suggest, never write.** Pending changes render a command for the human to run. The app
  never auto-applies, and never emits `--force`.
- No LLM calls, no email, no cron, no outbound HTTP from the server. Zero.
- Absent rows are preserved — a key missing from a snapshot is not a deletion.
  `followups` and `reply_suggestions` are the only full-replace tables.
- `queue_items.reviewed` is a local flag; never touch it on ingest.
- Migrations are additive and idempotent (`IF NOT EXISTS`). Never destructive.
- No string interpolation into raw SQL.
